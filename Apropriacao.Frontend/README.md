# Frontend de Apropriação

Interface Angular 18 para selecionar o mês, os dias e a planilha de atividades que serão enviados à API.

## Desenvolvimento

Na raiz do repositório:

```powershell
npm.cmd --prefix .\Apropriacao.Frontend install
npm.cmd --prefix .\Apropriacao.Frontend start
```

A aplicação fica disponível em <http://localhost:4200> e espera a API em <http://localhost:5254>.

## Build e testes

```powershell
npm.cmd --prefix .\Apropriacao.Frontend run build
npm.cmd --prefix .\Apropriacao.Frontend test
```

Consulte o [README principal](../README.md) para configuração do backend, Playwright, credenciais locais, formato da planilha e fluxo completo.
